# CLAUDE.md — OpsWeave Entry Point

See [AGENTS.md](./AGENTS.md) for full engineering mandate, principles, and package boundaries.

## Root Commands

- `pnpm install` : Install dependencies
- `pnpm dev` : Start dev servers
- `pnpm build` : Build all packages and apps
- `pnpm lint` : Run ESLint
- `pnpm typecheck` : Typecheck entire monorepo
- `pnpm test` : Run Vitest unit tests
- `pnpm test:coverage` : Run tests with coverage
- `pnpm test:e2e` : Run Playwright E2E tests
- `pnpm format:check` : Verify formatting
- `pnpm check` : Run format, lint, typecheck, and unit test checks
